# PivotIQ UX Audit — 2026-04-07

## Summary

PivotIQ has a strong product spine: task-level exposure, pivot ranking, market grounding, skill gaps, and a roadmap. The main UX problem is that the strongest data often appears as prose-heavy cards instead of immediate visual patterns.

The product should feel like a career cockpit, not a PDF report inside a web page.

## What Is Working

- The visual direction is distinct: warm editorial background, dark navy, orange, teal, serif display typography, and glassy cards.
- The audit flow is short enough to complete and now uses clearer task exposure colors.
- The report has meaningful structured data: task risk, pivot match, profile fit, live openings, missing market skills, proof assets, and roadmap progress.
- The market grounding layer gives PivotIQ a defensible anti-hallucination story.

## Biggest Weak Spots

- Too much information is stacked as similar cards, which makes important differences harder to see at a glance.
- The report asks users to read before it helps them orient visually.
- Market confidence used to sound negative because raw ranking reasons were exposed too directly.
- The 12-week roadmap is useful but still looks more like a checklist than a journey.
- The homepage has visual polish, but the report experience is where the product needs to feel most premium.
- Internal catalog quality visibility is now improved, but `/internal/job-catalog` still needs access control before any broader deployment exposure.

## Changes Made In This Pass

- Added a task exposure mix chart to the report Breakdown tab.
- Added a pivot evidence map to the Pivot Paths tab.
- Added a roadmap journey map to the Plan tab, grouping the 12-week plan into three visual phases with progress bars, week chips, and proof checkpoints.
- Added a compact `Why this recommendation?` explainer near the report hero that connects user evidence, live-market requirements, proof to build, and confidence level.
- Updated report market-confidence copy to show clearer labels like:
  - `Market-backed, proof needed`
  - `Model-led, verify with postings`
  - `Early market signal`
- Clarified audit Step 2 task-card colors:
  - green = low exposure
  - orange = medium exposure
  - red = high exposure
- Removed the confusing `FIT` badge from audit task cards.

## Next UX Priorities

1. Add a market-confidence badge directly beside the active pivot title for faster scanning.
2. Add a lightweight report tab onboarding strip: `Exposure -> Pivots -> Plan`.
3. Improve empty states so `/report` without data feels like a guided restart rather than a dead end.
4. Add authentication or admin-only protection around `/internal/job-catalog`.
5. Run browser-level visual QA when `agent-browser` or another screenshot tool is available.
